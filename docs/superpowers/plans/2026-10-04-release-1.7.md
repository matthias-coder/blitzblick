# Release 1.7.0 implementation plan

Spec: `docs/superpowers/specs/2026-10-04-release-1.7-design.md`. One commit per task, `npm test` green after each, `npm run precache` whenever `js/`, `css/`, `assets/`, `index.html` change.

1. **Grade + level model** — `js/levels.js` (grades, timing defaults, ladder lookup, playable level); `LADDERS` and step-based `createTask` in all four exercises; `arithmetic.js` (Plus + Minus) replaces `addition.js`; Zwanzigerfeld + pattern pool in `quantity-layout.js`; step-based `adaptive.js` with mastery; `session.js` level-up at round end; `profiles.js` new settings (`grade`, `hold`, `letters.lineature`), `setGrade`, `setLevel`, removed content settings; schema 2 migration (`js/migrate-v1.js`, `storage.js`). Unit tests rewritten for the new contract.
2. **Stickers by exercise × level** — `rewards.js` pages with `exercise`/`level`, `reached`, fallback chain; album grouped by exercise; round end shows level-up and opened page.
3. **Parent area** — Klassenstufe (with confirm), per-exercise level picker + hold, progress tab with level/step/mastered, removed controls, lineature switch.
4. **Shorter rounds** — `ROUND_LENGTH` 5, `STICKER_MIN_CORRECT` 4, ratio thresholds, phrases.
5. **Grundschrift + Lineatur 1** — font asset + OFL, `--font-school`, `svg()` helper, `js/ui/lineatur.js`, letters stimulus.
6. **Menu lettering** — `menuTitle`, tile label, CSS.
7. **e2e + release** — update Playwright specs, CHANGELOG, version, precache, merge `--no-ff` into `main`, tag `v1.7.0`, push after confirmation.
