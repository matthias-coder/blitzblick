# Addition Stages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Append "Plus bis 5" / "Plus bis 10" stages to the `quantity` and `digits` exercises, shown 2.5× longer, switchable per exercise in the parent area.

**Architecture:** A tiny shared module `js/exercises/addition.js` holds the constants and the addend generator. Each exercise appends `{ add: true, sum }` stages after its regular stages and branches in `createTask` / `renderStimulus` / speech on `stage.add` / `task.stimulus.add`. Tasks carry `durationFactor`; `session.nextTask` scales the flash duration. With adaptive timing off, exercises stay on their top *regular* stage (new optional `fixedComplexity`).

**Tech Stack:** Vanilla ES modules, no build; unit tests `node --test` (`npm test`), e2e Playwright (`npx playwright test`). Repo: `privat/blitzblick`, branch `feat/1.5`. Commit with the repo-local noreply identity (already configured); end messages with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Keep LF line endings.

**Spec:** `docs/superpowers/specs/2026-10-04-addition-design.md`

## Global Constraints

- Addition sums: `[5, 10]`; addends `a, b ≥ 1`, `a + b ≤ sum`. No subtraction, no sums above 10.
- Display factor for addition tasks: `2.5`; adaptive engine keeps the unscaled base duration.
- `settings.quantity.addition` and `settings.digits.addition`, default `true`.
- quantity addition stages only for `sum <= settings.quantity.max`; digits addition stages independent of `settings.digits.range`.
- Stage labels: `Plus bis 5`, `Plus bis 10`. Speech (German): quantity prompt `Wie viele waren es zusammen?`, solution `${a} und ${b} sind ${answer}.`; digits prompt `Wie viel ist das zusammen?`, solution `${a} plus ${b} ist ${answer}.`
- Child area has no text except digits/"+"; motion rules unchanged.

## Review Focus

1. Adaptive timing off ("Feste Dauer") — today it plays the top stage; with addition it must stay on the top regular stage, not jump to pure addition. (Task 1 + tests in Tasks 2/3.)
2. Parent switches addition off while the stored level sits on an addition stage — level must clamp back to the top regular stage. (Task 1 test.)
3. Old stored profiles without `addition` keys — must load with `addition: true` and keep their level indexes. (Task 1 test.)
4. `quantity.max` 3 or 4 — no addition stage at all; max 5/6/8 — only "Plus bis 5". (Task 2 test.)
5. "3 + 2" text must fit the fixed stage on a 360 px phone without wrapping. (Task 3 CSS + Task 4 e2e on the phone project.)

import { randInt } from '../rng.js';

// "Plus" stages appended on top of quantity and digits
export const ADD_SUMS = [5, 10];
export const ADD_DURATION_FACTOR = 2.5;

export function addends(rng, sum) {
  const a = randInt(rng, 1, sum - 1);
  return { a, b: randInt(rng, 1, sum - a) };
}

export function addStages(enabled, maxSum = Infinity) {
  return enabled ? ADD_SUMS.filter((sum) => sum <= maxSum).map((sum) => ({ add: true, sum })) : [];
}

export const addLabel = (sum) => `Plus bis ${sum}`;

export function nextTask(round, profile, rng) {
  const ex = EXERCISES[round.exerciseId];
  const s = profile.settings;
  const maxC = ex.maxComplexity(s);
  const eff = effectiveLevel(round.level, s.timing, maxC, ex.fixedComplexity ? ex.fixedComplexity(s) : maxC);
  const task = ex.createTask({ ...round.level, complexity: eff.complexity }, s, rng, round.ctx);
  return { ...round, task, durationMs: Math.round(eff.durationMs * (task.durationFactor ?? 1)), awaiting: true };
}

function regularStages(settings) {
  const maxes = MAXES.filter((m) => m <= settings.quantity.max);
  const list = maxes.length ? maxes : [3];
  const layout = settings.quantity.layout;
  if (layout === 'structured' || layout === 'random') return list.map((max) => ({ max, layout }));
  return list.flatMap((max) => [{ max, layout: 'structured' }, { max, layout: 'mixed' }]);
}

export function stages(settings) {
  return [...regularStages(settings), ...addStages(settings.quantity.addition, settings.quantity.max)];
}

export function maxComplexity(settings) { return stages(settings).length - 1; }
export function fixedComplexity(settings) { return regularStages(settings).length - 1; }
