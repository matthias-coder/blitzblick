# UX review and polish plan (2026-10-04, after 1.3.0)

Audience: children ~4–6 (pre-readers; navigate by picture, colour, feedback) and parents (set up, judge quality).

## Keep
- Andika, coloured syllables, large calm stimulus, big touch targets, dot hints under digits, no text in the child area.
- Kawaii raster artwork (avatars, objects, robot, decor) is the strongest asset — everything should match it.

## Findings
1. Two art styles side by side — worst at round end (flat SVG sticker under kawaii "YAY!" + gold star) and in album tabs.
2. Empty space: answer phase leaves ~80 % of the tablet screen empty lavender; menu tiles float mid-screen; stimulus stage size differs per exercise.
3. Correct answers feel like nothing (button turns green, dot turns yellow); wrong answers get more attention than right ones.
4. Progress dots (light blue / dark blue = wrong / yellow = right) are not readable for a 5-year-old.
5. Menu tiles are text on colour ("123", "ABC", "Mama"); orange 4th tile is off-palette.
6. Parent area uses native blue checkboxes/selects and millisecond inputs — looks like browser defaults.

## Package 1 (agreed, do first)
1. **Replace the 40 SVG stickers** (animals, vehicles, space, sea, dinos) with raster cut-outs from user-generated sheets; same IDs so collections survive; pages switch to `format: 'png'`; old SVGs and their gen-svgs.mjs code removed.
2. **Fixed stage**: one white card of constant size for every exercise; it stays during the answer phase (with a "?" or the robot peeking over the edge) — no empty screen, no layout jump.
3. **Star progress**: outlined stars that fill gold with a short pop on a correct answer, stay grey on a wrong one (replaces the dots).
4. **Per-answer reward**: correct → button springs, a small star flies into the progress track, robot cheers (`_lokal/extracted/mascot/robot-cheer.png` exists, not yet in assets); wrong → gentle shake instead of alarm red. All motion off under `prefers-reduced-motion`.

## Package 2 (later)
5. Menu as full-screen 2×2 grid with illustrations from existing assets (apples, blocks 1-2-3, book, drawing book), four harmonised tile colours, robot greeting with speech bubble.
6. One tactile "candy" button system (thick bottom edge that sinks on press, top highlight, radius by hierarchy).
7. Round end as a reveal (sticker flips in with a ray burst, then flies into the album button).
8. Parent area: custom toggles, segmented controls instead of selects, duration slider in seconds; welcome screen with the robot on first start.
9. Convert raster assets to WebP.
